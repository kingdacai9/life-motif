人生母题是一套由老金发起的AI深度人生访谈方法。

把Skill和HTML母版交给AI，它会通过35个人生板块陪你回顾过去：出生、童年、家庭、关系、失败、成功、工作、金钱、价值观，以及你此刻正在面对的生活。

访谈结束后，AI不会只给你一串性格标签。它会根据你讲过的具体经历，整理完整人生档案，提炼3—5个反复出现的人生母题，并生成一份可以保存、打开和继续更新的HTML人生母题地图。

## 你会得到什么

- 一份完整的人生档案；
- 3—5个有经历和现实证据支持的人生母题；
- 一份可独立打开的HTML人生母题地图；
- 6张可以下载和分享的视觉卡片；
- 一份方便以后继续更新的人生母题通行证。

人生会变，母题也不是终身判决。三个月、半年以后，你可以把保存好的HTML重新交给AI，补充这段时间发生的新变化。

## 开始前，下载两个文件

普通用户只需要：

1. [`SKILL.md`](SKILL.md)
2. [`life-motif-map-template.html`](assets/life-motif-map-template.html)

也可以直接下载 [人生母题2.0最新完整ZIP](https://github.com/kingdacai9/life-motif/archive/refs/heads/main.zip)，解压后找到这两个文件。

不要修改公版HTML。完成访谈后，AI会另存你的个人版本。

> 请使用能够读取附件并生成独立文件的AI工具。如果当前平台只能展示代码，不能交付可下载的HTML，请换到支持文件生成的平台继续。

## 请选择你的入口

| 第一次使用 | 做过人生母题1.0 |
| --- | --- |
| 从35个人生板块开始，建立完整基线 | 读取旧报告或聊天记录，只补缺失和变化 |
| 不需要一次答完，可以分多次进行 | 不需要重新回答35个板块 |

### A. 第一次使用

新开一个AI对话，上传 `SKILL.md` 和 `life-motif-map-template.html`，然后发送：

```text
请按照我上传的《人生母题2.0》Skill，开始我的人生母题访谈。
我是第一次使用，请按照35个人生板块依次进行，一次只问一个问题，并根据我的回答适当追问。
在访谈完成、我确认母题后，请直接生成完整人生档案和可以下载保存的人生母题HTML。
```

AI会一次问一个问题。你可以说“今天先到这里”，下次再继续。任何不想回答的问题都可以跳过。

### B. 从1.0升级到2.0

新开一个AI对话，上传：

- `SKILL.md`
- `life-motif-map-template.html`
- 你的1.0报告、聊天记录、回答文档或最终摘要

然后发送：

```text
请使用我上传的《人生母题2.0》Skill，把我的人生母题1.0升级到2.0。
请完整读取旧资料，不要让我重新回答35个问题。先给我一份迁移摘要，告诉我你读取到了哪些关键经历、母题和当前状态。
只对关键缺失、矛盾和1.0之后的变化进行追问。等我确认后，请直接生成完整的2.0报告和可以下载保存的人生母题HTML。
```

旧资料越完整，迁移越顺。如果只剩一份摘要，AI会补问建立可靠基线所需的内容；如果资料已经丢失，它会明确告诉你能够恢复到什么程度。

## 以后怎么更新

请保存好首次生成的个人HTML，例如：

```text
张三-人生母题地图-V2.0-2026-08-24.html
```

工作、关系、健康、金钱或自我认识发生变化时，新开一个对话，上传：

- `SKILL.md`
- 上一次保存的个人HTML

然后说：

```text
请读取我上传的人生母题HTML，并按照《人生母题2.0》Skill更新我的人生母题。
不要重新进行35个板块访谈。请先告诉我你读取到的当前版本、核心母题、上次更新时间和未来观察重点，然后围绕这段时间的新变化向我提问。
在我确认更新内容后，请生成新的HTML版本，保留原来的历史记录，不要覆盖旧文件。
```

你也可以直接说“更新人生母题”“补充近况”“做一次月度复盘”或“做一次季度复盘”。

新版本会从V2.0更新为V2.1、V2.2……旧记录不会被覆盖。

## 保存与隐私

个人HTML里可能包含关系、健康、金钱和内在状态等私人信息。不要公开上传完整HTML，也不要随意转发。

需要分享时，请使用HTML中经过隐私处理的6张分享卡。使用第三方AI前，也请先了解对应平台的数据与隐私政策。

人生母题用于自我回顾和模式观察，不是心理诊断、医疗建议，也不是对一个人的终局判断。
