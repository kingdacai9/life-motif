看见你的来时路，找到你的人生母题。一套 AI 深度人生访谈系统。把它交给任何一个 AI，AI 就会变成你的私人访谈师——通过 35 个话题，陪你把从出生到现在的人生经历、重要记忆、三观形成过程，一点一点挖出来。

- **写自传**：不是流水账，是从根系到当下的完整人生叙事

- **梳理人生故事**：如果你不知道此生来人间的意义是什么，帮你找到最真实的原点故事
- **深度自我理解**：为什么你是现在这个样子？答案都在你的人生里

## 怎么用？（三种方法，从最简单的开始）

### 方法一：直接发文件（最简单，人人可用 ⭐推荐新手）

1. 下载本页面里的 `人生母题` 文件夹中的 `SKILL.md` 文件（点开文件 → 右上角下载按钮）
2. 打开你常用的 AI 软件，把这个文件发到聊天框里
3. 打一句话："**请照这个文档访谈我，开始人生母题**"
4. AI 会开始问你问题，你回答就行了

就这么简单。AI 会一个板块一个板块地陪你聊，你随时可以说"今天先到这儿"，下次接着来。

### 方法二：装成"技能"（装一次，以后随叫随到）

如果你用的是 WorkBuddy 或 Claude Code 这类支持"技能包"的工具：

**WorkBuddy 用户**：把 `SKILL.md` 文件发给 WorkBuddy，说"帮我把这个安装成技能"，它自己就装好了。以后任何时候说"开始人生母题"就能启动，不用再发文件。

**Claude Code 用户**：把整个 `人生母题` 文件夹，放到你项目目录下的 `.claude/skills/` 文件夹里。之后说"开始人生母题"即可启动。

### 方法三：复制粘贴（连文件都发不了的时候用）

打开 `SKILL.md`，全选、复制，粘贴到 AI 聊天框里，再说一句"照这个访谈我"。效果一样。

## 使用小贴士 💡

- **不用一口气做完**。35 个板块，可以每天聊 1-3 个，像写日记一样慢慢来
- **答得越具体越好**。别说"我小时候挺幸福的"，说一个具体的画面、一件具体的事
- **任何问题都可以跳过**。不想答就说"跳过"，AI 不会逼你
- **聊到难受了就暂停**。这是挖自己的人生，有情绪很正常，照顾好自己优先
- **有两种模式可选**：自助模式（你自己答，AI 引导）和陪访模式（真人访谈师带你做，AI 负责记录提炼）。如果你一个人做，选自助模式就行

## 常见问题

**Q：我的回答会泄露隐私吗？**
A：这套系统只是一份"访谈提纲"，你的回答存在你自己的 AI 对话里，和你平时跟 AI 聊天一样。涉及特别私密的内容，建议使用有隐私保护的 AI 工具。

**Q：一个人做，感觉挖不深怎么办？**
A：很正常。自助模式适合轻度梳理；如果你想做一次真正的深度挖掘，可以找真人访谈师陪你做"陪访模式"（见下方联系方式）。

**Q：35 个板块要做多久？**
A：自助模式，每个板块 15-25 分钟，全部做完大约 10-15 小时。不用一次完成，分多次慢慢来效果更好。

**Q：做完了我能得到什么？**
A：一份结构化的人生自传素材 + 3-5 个人生母题清单。你可以用它来写文章、做内容、做人生决策，或者纯粹留给自己。
