# 人生母题 Life Motif 2.0

> 经营人生之前，先看清你是谁。

## 人生母题是什么

人生母题是一套由老金发起的AI深度人生访谈方法。

它试图回答的不是“你属于哪一种人”，而是三个更具体的问题：

- 哪些经历塑造了今天的你？
- 哪些模式在工作、关系、金钱、身体和选择中反复出现？
- 当这些模式再次出现时，你能否更早看见，并做出新的选择？

它不是一份几分钟完成的性格测试。AI会通过35个人生板块与你进行多轮深度访谈，从出生、童年、家庭、关系、失败与成功，一直谈到工作、价值观、当下状态和未来选择。

访谈结束后，AI会根据你讲述的具体经历，提炼3—5个反复出现的人生母题。每个母题都需要经历和现实证据支持，也允许被未来的生活继续验证、减弱或修正。

## 35个人生板块意味着什么

第一次建立人生母题档案的新用户，必须完成35个人生板块的访谈。只有覆盖足够完整的人生资料，AI才有可能区分长期模式与一次性事件，避免根据少量信息仓促定义一个人。

35个板块不是让你一次填写一张超长问卷。AI会一次只问一个问题，并根据你的回答继续追问。你可以分多次完成，但不应跳过完整基线，直接要求AI生成结论。

完成过人生母题1.0的用户是例外：原有回答已经覆盖了主要人生资料，因此可以迁移升级，不需要重新完成35个板块。

## 开始前准备两个文件

下载本项目后，普通用户只需要使用：

1. [`SKILL.md`](SKILL.md)：规定AI如何访谈、迁移、提炼、生成和更新；
2. [`life-motif-map-template.html`](assets/life-motif-map-template.html)：人生母题地图的公版视觉母版，同时包含通行证数据规范。

不要修改公版文件。AI完成访谈后会另存你的个人HTML，不会覆盖母版。

建议使用能够读取附件并生成独立文件的大模型。如果当前平台只能在对话里展示代码，不能提供可下载的HTML文件，请换到支持文件生成的平台继续。

## 请选择你的入口

### A. 第一次使用人生母题的新用户

新用户需要从35个人生板块开始，建立完整基线。

打开一个新对话，上传：

- `SKILL.md`
- `life-motif-map-template.html`

然后发送：

```text
请按照我上传的《人生母题2.0》Skill，开始我的人生母题访谈。
我是第一次使用，请按照35个人生板块依次进行，一次只问一个问题，并根据我的回答适当追问。
在访谈完成、我确认母题后，请直接生成完整人生档案和可以下载保存的人生母题HTML。
```

接下来AI应该：

1. 一次询问一个板块，不一次抛出35道题；
2. 对关键经历、感受、信念和选择进行必要追问；
3. 区分事实、用户判断、重复证据和AI推测；
4. 完成35个板块后提出3—5个候选母题；
5. 先让你确认母题名称与解释是否准确；
6. 得到确认后再生成正式交付物。

### B. 已经完成1.0的老用户

1.0用户不需要重新完成35个板块。AI应优先读取旧资料，只补充关键缺失、矛盾和1.0完成以后发生的变化。

打开一个新对话，上传：

- `SKILL.md`
- `life-motif-map-template.html`
- 你的1.0报告、聊天记录、回答文档或最终摘要

然后发送：

```text
请使用我上传的《人生母题2.0》Skill，把我的人生母题1.0升级到2.0。
请完整读取旧资料，不要让我重新回答35个问题。先给我一份迁移摘要，告诉我你读取到了哪些关键经历、母题和当前状态。
只对关键缺失、矛盾和1.0之后的变化进行追问。等我确认后，请直接生成完整的2.0报告和可以下载保存的人生母题HTML。
```

不同资料情况会进入不同路径：

- 有完整报告或聊天记录：完整材料迁移；
- 只有最终摘要：摘要迁移，并补充形成可靠基线所需的内容；
- 原始资料已经丢失：轻量重建，并明确标注资料范围和可信度。

AI不能假装已经读取缺失的材料，也不能为了升级形式而让老用户重新完整测试。

## 完成后你会得到什么

无论是新用户完成35板块，还是1.0用户完成迁移，最终都应得到：

- 一份完整的人生档案：记录关键经历、人物、转折、信念形成与当前状态；
- 3—5个核心人生母题：包含支持证据、反向证据、触发、旧反应、代价和新选择；
- 一份可以独立打开的HTML人生母题地图；
- 6张可以下载和分享的视觉卡片；
- 内嵌在HTML里的机器可读通行证；
- 一份方便阅读和复制备用的文字版通行证。

HTML不是聊天窗口里的预览，也不是一段需要用户自己复制保存的代码。AI应该直接交付可以下载、双击打开的独立 `.html` 文件。

## 以后如何更新人生母题

请妥善保存首次生成的个人HTML，例如：

```text
张三-人生母题地图-V2.0-2026-08-23.html
```

三个月、五个月以后，或者工作、关系、健康、金钱和自我认识发生重要变化时，重新打开一个新对话。

这一次只需上传：

- `SKILL.md`
- 上一次保存的个人HTML

然后发送：

```text
请读取我上传的人生母题HTML，并按照《人生母题2.0》Skill更新我的人生母题。
不要重新进行35个板块访谈。请先告诉我你读取到的当前版本、核心母题、上次更新时间和未来观察重点，然后围绕这段时间的新变化向我提问。
在我确认更新内容后，请生成新的HTML版本，保留原来的历史记录，不要覆盖旧文件。
```

用户也可以说“更新人生母题”“补充近况”“做一次月度复盘”或“做一次季度复盘”，不需要记忆唯一口令。

更新后的文件会依次成为V2.1、V2.2……。新材料会被标记为新增、强化、减弱、修正或结束，原有证据和历史记录不会被覆盖。

## 为什么要保存个人HTML

个人HTML不仅是一张可视化地图，还保存了以后更新需要的数据，包括：

- 资料范围与版本；
- 35个板块的访谈摘要；
- 关键人生节点；
- 母题及其支持和反向证据；
- 当前状态与未来观察重点；
- 历次更新记录。

因此，保存个人HTML，就等于同时保存了人生母题地图和持续更新的基线。以后优先上传这份HTML，不必重新讲述完整人生。

## 保存与隐私

完整个人HTML可能包含经历、关系、健康、金钱和内在状态等私人信息：

- 不要把完整个人HTML公开上传或随意转发；
- 对外分享请使用HTML中经过隐私处理的6张分享卡；
- 使用第三方大模型前，请自行了解该平台的数据与隐私政策；
- 公版HTML母版不包含任何真实用户资料。

## 使用边界

人生母题用于自我回顾、模式观察和长期记录，不是心理诊断、医疗建议或对一个人的终局判断。报告中的母题是等待现实继续验证和修正的假设。
